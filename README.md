# UMBento

Новый сайт Uminers. Главная — не лендинг, а **доска**: bento-сетка, где всё
видно на одном экране, каждая плитка ведёт в раздел, и три плитки читают, что
посетитель уже сделал.

```
npm install
npm run dev      # http://localhost:8900
npm run build
```

## Что новое

**Жёлтый как коммерческий сигнал.** `--offer: #FFD400` — только оффер, скидка,
срок, наличие. Не навигация, не украшение, не больше одной плитки на экран.
Бирюза остаётся брендом и навигацией. Приём взят из `refs/11.jpg`, но жёлтый там
занимал 25–36% экрана как заголовок объекта; здесь это 6.25% доски — вторая по
заметности вещь после героя, что и проверяется правилом: **убери жёлтый —
порядок чтения меняется.**

**Слот цены, который не схлопывается.** 98 из 124 позиций без опубликованной
цены. Слот фиксированной высоты 44 px; при `price: null` его занимает не серое
«по запросу», а активная кнопка «Request price →». Отсутствие цены выглядит
активнее цены, а не как недоделанный каталог.

**Доска как состояние сделки.** Плитка листа запроса меняет цвет и считает
позиции; калькулятор берёт суммарную мощность из корзины через
`specPowerWatts()`, а не показывает абстрактный пример; плитка статуса
появляется черновиком. Ни один из шести рефов так не делает — там либо чужой
дашборд, либо статичный маркетинг.

## Геометрия

`--wrapper: 1400` · `--shell: 24` · `--gap: 16` → колонка ровно **98.0 px** без
субпиксельных швов. Эти три числа связаны, менять по отдельности нельзя.
Высота ряда `--row: 184` выведена из первого экрана 1440×900: четыре ряда
занимают 784 из 796 доступных, остаток 12 px — видимая кромка пятого ряда, то
есть обещание небольшого скролла. Раскладка по всем брейкпоинтам —
`docs/ART-DIRECTION.md` §3, размещение плиток — в `HomeView.vue` внизу файла.

Только главная (`.board--tight`) держит фиксированный ритм строк; на остальных
страницах ряды по содержимому — строка фильтров, растянутая до 184 px, это дыра,
а не ритм.

## Открытые вопросы — решать владельцу

1. **`background and key visuals/` не используется.** Все 7 файлов — чужие
   продуктовые рендеры с Pinterest (имена — md5-хеши, ширина 734–750 px). Один
   подписан «RTX 4090 TI» — такой карты NVIDIA не выпускала. Ни один не тянет
   фон плитки шире 600 px. Копии лежат в `docs/_quarantine/`, вне `public/`.
   Вместо них — своя съёмка и продуктовые кадры каталога.
2. **Права на продуктовую фотографию каталога.** Вопрос унаследован из текущего
   проекта и записан в шапке `src/data/catalogue-gpu.js`: часть ассетов
   байт-в-байт совпадает с файлами exxactcorp.com. Не решено, перенесено как
   есть.
3. **Не используются:** `team-crew.jpg` (AI-апскейл, лица изменены нейросетью),
   `container-aircool.png` (чужой логотип «РусТехМаш» на бортах),
   `logistics-yard.jpg` (читаемый госномер). `gpu-crate.jpg` назван неверно —
   это разгрузка тентового полуприцепа, а не ящик с GPU.
4. **Офферы — заглушки.** Все три в `src/data/site.js` помечены `draft: true`,
   плитка рендерит «Ask the desk» вместо цифры. Флаг снимать только вместе с
   подтверждённой скидкой и сроком.
5. **Форма запроса без бэкенда.** `QuoteView` собирает текст и отдаёт его
   почтовому клиенту; на экране это сказано прямо. Нужен эндпоинт.
6. **Тексты** написаны мной, не проходили через spinoza — фактических
   утверждений о компании там минимум, но перед публикацией стоит прогнать.
